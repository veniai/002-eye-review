# UI 收敛定稿方案：唯一视觉语言（Apple-grade Editorial）

> 状态：**已落地**（2026-08-06，411/411 测试通过）。

> **2026-08-06 设计修正**：第一版只换了色值、仍保留"卡片+描边+阴影"的旧框架，是对 Apple 审美的误读。真正的纪律是——**普通表面零阴影、零描边**，分组靠留白，分隔靠 hairline，阴影只属于浮层（弹窗/菜单）。壳层不做玻璃边框，导航选中态用灰底而非白底描边，hover 不做位移动效。token 表已按此修正。本文档是后续一切 UI 修改的唯一依据。
> 与 `README.md`（设计总纲）的关系：总纲定义了信息设计原则与数据页 token，本文档把该语言**升级为全产品唯一语言**，并补齐暗色映射、护眼体验域、设置页组件规范与风格开关下线计划。

---

## 一、决策（不再讨论的）

1. **只保留一种界面风格**。`ui_visual_style` 的 a/b/c 三档开关整体下线：删除外观设置里的风格选择 UI、删除 `ui-style-a`/`ui-style-b` 覆盖层、删除配置字段（迁移时忽略旧值）。用户不再面对"皮肤"概念。
2. **唯一语言 = 现有设计总纲的 slate/蓝 editorial 体系**，按 Apple 级标准收紧执行：大量留白、纤细分隔线（不用重描边卡片）、克制的阴影、玻璃拟态只用于 shell 框架层、图表与分类色板不变（已过色盲校验）。
3. **护眼是"体验域"不是"皮肤"**：休息遮罩/提醒条/复盘卡必须与主 App 同一血统（同字体、同字阶、同控件语言），仅允许氛围层不同（深色静谧底 + 缓慢呼吸动效）。糖果色渐变卡、彩色 orb 全部废弃。
4. **新功能入口原则**：设置类进设置对应标签页；数据呈现类进对应数据页；不新增游离入口、不新增视觉变体。

## 二、视觉 token（唯一来源，app.css 落地）

### 亮色
| Token | 值 | 用途 |
|---|---|---|
| `--surface-page` | `#f5f5f7` | 页面底（Apple 官网底色系） |
| `--surface-featured` | `#ffffff` | 卡片面 |
| `--surface-subtle` | `#f8fafc` | 卡内次级面、悬停底 |
| `--ink` / `--ink-2` / `--ink-3` | `#1d1d1f` / `#6e6e73` / `#86868b` | 标题数值 / 正文 / 辅助（Apple 文字色阶） |
| `--line` / `--line-soft` | `rgba(0,0,0,.10)` / `rgba(0,0,0,.05)` | **仅分隔线用**；卡片/面板不描边 |
| `--primary` / `--primary-soft` | `#3b82f6` / `#dbeafe` | 主按钮、选中态、洞察条 |
| `--r-card` / `--r-inner` / pill | 16px / 12px / 999px | 一级卡 / 嵌套面板输入框 / chip·分段钮 |
| 阴影 | **普通表面一律无阴影**；仅浮层（弹窗/菜单）`0 12px 32px rgba(0,0,0,.10)` | 阴影只属于浮层，卡片/面板零阴影 |

### 暗色（Apple dark 映射，替换现 GitHub 色）
| Token | 值 |
|---|---|
| `--surface-page` | `#000000` |
| `--surface-featured` | `#1c1c1e` |
| `--surface-subtle` | `#2c2c2e` |
| `--ink` / `--ink-2` / `--ink-3` | `#f5f5f7` / `#98989d` / `#6e6e73` |
| `--line` / `--line-soft` | `rgba(255,255,255,.14)` / `rgba(255,255,255,.07)` |
| `--primary` | `#0a84ff` |

### 字体与字阶（不变纪律）
SF Pro Display/Text → PingFang SC → Segoe UI Variable → Microsoft YaHei；数字一律 `tabular-nums`。
页题 22/700 · 卡题 15/650 · 正文 14 · 辅助 12–13 · KPI 数值 1.8–1.9rem/650。徽标最小 10px 仅用于 Beta/计数角标。

### Shell 框架
保留 C 风格的圆角框架骨架（侧栏/主区双框架 + macOS 顶部留白），但：删除 ambient 渐变光斑；自定义背景图功能保留为外观设置次要项，默认关。

## 三、逐页改造清单

### 1. Shell / 侧边栏
- 导航项：active 态 = `--surface-featured` 白底 + 1px `--line` + 微阴影（亮）/ `#2c2c2e`（暗）；去掉彩色底。
- 品牌区精简：logo + 名称一行；录制状态收敛为一行（状态点 + 文字 + 暂停按钮），不做大面板。
- 底部工具带：主题切换、语言 合并为一行图标钮，等宽 36px、hover 出 `--surface-subtle` 圆角底。

### 2. 设置页
- 保留 7 个标签的信息架构；标签导航改为**左侧纵向列表**（macOS 系统设置式）或保持顶部横排但统一成分段控件样式——落地时按宽度实测选一，规范：选中态白底+微投影，无彩色。
- 所有分组统一 `settings-card`：22px 圆角白卡、15/650 卡题、13px 辅助描述、行内控件右对齐（macOS 表单行模式）。
- 删除"界面风格"整个区块（随 a/b/c 下线）。
- 表单控件统一：输入框/下拉 14px 圆角 + `--line` 描边 + focus 时 `--primary` 2px 外环；开关用 iOS 式 pill switch。

### 3. 护眼体验域（重点重做）
- **休息遮罩 EyeCareOverlay**：深色静谧全屏——`radial-gradient` 从 `#0b1220` 到 `#000`；中央内容列：细 eyebrow（12px 字距 .2em、`--ink-3`）→ 标题 28–34px → 副文 16px → **巨大倒计时**（clamp 72–160px、weight 600、`tabular-nums`、青蓝色 `#7dd3fc`）→ 细进度环或 6px 细进度条（`--primary` 渐变）→ 底部紧急出口提示 12px。唯一动效：背景一个 24s 缓慢呼吸的径向光晕（亮度 6%→10%），无任何彩色 orb。
- **Pre-break 提醒条**：与 Toast 同一组件语言——玻璃拟态圆角条（`backdrop-filter: blur(20px)`、22px 圆角、`--line` 描边），图标用眼睛 SVG（非"◌"字符），倒计时数字 `tabular-nums` 右对齐。
- **复盘卡 EyeCareRecap**：改为标准模态卡——22px 圆角、backdrop blur 深色遮罩、卡题+KPI 行（总休息时长大号数字）+ 双栏明细列表（与总纲"明细双栏"一致）+ 单个主按钮（`--primary` 实心 pill）。删除手写浅绿卡底。

### 4. 数据页（概览/时间线/日报/问答/关于）
- 已按总纲定稿的页面只做 token 对齐：把硬编码色值/圆角全部替换为上表变量；暗色从 GitHub 色迁到 Apple 色。
- 分段控制器唯一形态：底 `#e9edf3`（亮）/`#2c2c2e`（暗）、12px 圆角、选中白底+微投影。

## 四、验收标准
- 任何页面截图中不出现：第二种卡片圆角体系、糖果色渐变、彩色装饰光斑、风格切换入口。
- 亮色/暗色下所有文本对比度 ≥ WCAG AA（4.5:1，辅助小字 ≥ 3:1）。
- 护眼三组件与主 App 并排截图，肉眼无法分辨"两套设计"。
- `grep -rn "ui-style-" src/` 结果为空。

## 五、不做的事
- 不改六色分类色板与图表规范（已过色盲校验）。
- 不改信息架构（路由、设置标签划分）。
- 不引入第三方 UI 组件库；所有组件保持项目内手写、token 驱动。
