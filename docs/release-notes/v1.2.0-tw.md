# Work Review v1.2.0

**發布日期**：2026-08-06

本次發布將整個產品收斂為單一 Apple 級視覺語言，並在同一基礎上重做護眼體驗。

## 調整

- **視覺語言全面收斂**：亮色遷移至 `#f5f5f7` 頁面底 + 22px 圓角白卡 + 細黑透明邊界；暗色從 GitHub 色系遷移至 Apple 深色（`#000` 底 / `#1c1c1e` 卡片 / `#2c2c2e` 次級面 + 半透明白邊界）。
- **介面風格開關下線**：移除 A/B/C 三套介面風格與外觀設定中的選擇入口，所有使用者統一使用同一套視覺；相關設定欄位、文案與測試同步清理。
- **護眼介面重做**：強制休息遮罩改為深色靜謐全屏（緩慢呼吸的冷色光暈 + 青藍漸層倒計時 + 細進度條）；休息前提醒條改為深色玻璃擬態；休息後的週期回顧改為標準模態卡片，與主介面同一血統。
- **側邊欄打磨**：導航選中態從彩色漸層改為白底細邊（暗色為次級面），去除位移動效；主色從 indigo 統一收斂到品牌藍。

## 移除

- 介面風格 A/B/C 切換（設定項 `ui_visual_style` 及其設定介面）。
