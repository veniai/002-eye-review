# Work Review v1.2.0

**Release date**: 2026-08-06

This release unifies the entire product under a single Apple-grade visual language and rebuilds the eye-care experience on the same foundation.

## Changed

- **One visual language**: light theme moves to a `#f5f5f7` canvas with 22px rounded white cards and hairline translucent borders; dark theme migrates from GitHub colors to Apple dark (`#000` background, `#1c1c1e` cards, `#2c2c2e` secondary surfaces, translucent white borders).
- **Style switcher removed**: the A/B/C interface style options and their settings entry are gone — everyone gets the same, single design. Related config fields, copy, and tests were cleaned up.
- **Eye-care rebuilt**: the forced-rest overlay is now a calm full-screen experience (slow breathing cool glow, gradient countdown, thin progress bar); the pre-break reminder is a dark glass-morphism strip; the post-break recap uses a standard modal card consistent with the main app.
- **Sidebar polish**: the active nav state uses a white hairline card instead of a colored gradient; the accent color converges from indigo to the brand blue.

## Removed

- The A/B/C interface style switcher (the `ui_visual_style` config and its settings UI).
