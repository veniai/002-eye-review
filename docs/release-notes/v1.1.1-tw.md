# Work Review v1.1.1

**發布日期**：2026-08-05

此版本僅移除桌寵功能，保留 Work Review 其餘能力，並新增獨立護眼休息系統。

## 新增

- 可設定的護眼計時器：預設工作 40 分鐘、強制休息 3 分鐘、自然離開門檻 5 分鐘，並提前 30 秒預告。
- 每塊顯示器同步顯示休息層，包含倒數、進度、外圍變暗、watchdog 恢復及隱藏故障出口。
- 休息結束並偵測到首次有效輸入後，才在主視窗顯示本輪工作回顧。

## 調整

- 僅移除桌寵視窗、素材、專屬設定、氣泡與主動提醒、點擊穿透及桌寵輸入擴充。
- 保留活動記錄、應用程式/網站統計、截圖、OCR、時間線、小時摘要、日報、匯出、工作助手、隱私、儲存、本地 API、Bot、更新與開機啟動。
- 舊 `break_reminder_*` 設定會確定性遷移到新的護眼設定。
- 護眼計時不依賴活動錄製、截圖、OCR、AI、網路或牆上時間調整。

## 驗證說明

自動化測試與 Windows 目標交叉編譯已通過。Windows 鎖定/睡眠、多螢幕、混合 DPI、熱插拔與遮罩繞過仍需依 `docs/eye-care/WINDOWS-VALIDATION.md` 完成實機矩陣。
