# Work Review v1.1.1

**Release date**: 2026-08-05

This release removes the desktop avatar while preserving the rest of Work Review, and adds an independent eye-care break system.

## New

- Eye-care timer with configurable defaults: 40 minutes of work, 3 minutes of forced rest, 5-minute natural-away threshold, and a 30-second warning.
- Synchronized overlays on every display, with countdown, progress, dimmed perimeter, watchdog recovery, and a hidden emergency release chord.
- A per-cycle recap shown in the main window only after the break ends and the first valid user input is detected.

## Changed

- Removed only avatar-specific windows, assets, settings, bubbles, proactive reminders, click-through behavior, and input extensions.
- Preserved activity recording, app/site statistics, screenshots, OCR, timeline, hourly summaries, daily reports, exports, work assistant, privacy, storage, local API, bots, updates, and autostart.
- Migrated legacy `break_reminder_*` settings deterministically to the new eye-care configuration.
- The eye-care timer is independent of recording, screenshots, OCR, AI, network availability, and wall-clock adjustments.

## Validation note

Automated tests and Windows-target cross-compilation passed. Windows lock/sleep, multi-display, mixed-DPI, hot-plug, and overlay-bypass behavior still require the physical test matrix in `docs/eye-care/WINDOWS-VALIDATION.md`.
